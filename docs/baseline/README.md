# 原版 Gogs 界面基准（截图归档 + 结构对照）

> 用途：原生 dsh UI（client/index.js）的视觉与结构基准。31 张真实原版截图，
> 与每个页面的结构/元素逐项对照。接口不变，仅对齐界面。
> 拍摄：admin 登录内核 :3400，1440×900。

## 页面索引（截图在 docs/baseline/）

## 本轮要重实现的页面（按原版逐像素对齐，接口不变）

优先级（用户指定"一点一点迁移"）：
1. **issue 详情**：左右栏布局（评论流 + 右侧 标签/里程碑/指派/参与者）
2. **issue 列表**：类型筛选（issue/PR 同列表）——原版该页同时列 issue+PR？核实后实现
3. **仓库主页**：文件列表相对时间、clone 行加"下载"按钮、发版出主导航（仅 stats 跳转）
4. **标签管理**：每行"N 个开启的工单"计数链接
5. **commits**：搜索框 + 相对时间
6. **wiki**：页面下拉选择 + "修改者于 X 修改"标注
7. **发版**：每条"此后已有 N 次提交" + **源码下载 zip/tar.gz**（宿主二进制透传）
8. **设置**：左栏导航（基本设置/协作者/分支/Web 钩子）+ 描述字数计数 + 官网字段
9. **分支**：概况/所有分支 二级 tab + 更改默认分支
10. **explore**：左栏（仓库/用户/组织）+ 行内 star/fork/最后更新
11. **用户主页**：左栏头像/邮箱/加入时间/关注者 + 仓库行 star/fork/时间
12. **admin**：左栏导航 + 构建信息/统计/监控
13. **deploy keys**（设置子页，内核 v1 已有端点）

说明：用户设置页（26-28）由 user-management 插件全权托管，原生 Git 插件不重复实现。
